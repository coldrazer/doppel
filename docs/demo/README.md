# Doppel · one-minute demo

[doppel-demo.mp4](doppel-demo.mp4) is a 60-second, 1920×1080, 30 fps product film with stereo electronic music and no voiceover.

The footage records the actual app: screenshot upload, live GMI vision generation, manual target correction, missed-click guidance, lesson completion, publication, and HTML export. Generation waiting time is shortened and labeled in the film. The editing uses deliberate camera crops and timing adjustments; the interface and model responses are real.

## Production

Actual app recordings captured with Playwright; composed with HyperFrames and GSAP; encoded with FFmpeg. Source artwork follows Doppel's orange, white, and charcoal palette. The repository banner was separately created with the built-in image-generation tool; it is promotional artwork rather than a screenshot.
